# v1 审查与构建记录（2026-10-01）

范围：已有 `v0.1.0` 的 Obsidian ↔ 飞书插件，维护版本号为 `0.1.1`。保留两种同步模式；不增加 Notion 接入。本次没有修改真实 Work 笔记、安装目录或飞书文档。

## 发现并修复

| 问题 | 处理 |
| --- | --- |
| 文档模式切换目标仍可能保留旧目录映射，文件模式未识别模式切换 | 两种引擎统一管理目标、模式和目录配置；变化后清空旧映射与图片缓存，重新对接 |
| 已确认计划没有绑定原配置和映射 | 对配置与映射生成摘要；预览后变更目标、规则或映射时拒绝旧计划 |
| 普通覆盖、删除、建立映射可能使用过期内容 | 上传前复核本地与远端；删除前复核双方状态；本地或远端恢复后停止删除；link 前复核哈希 |
| 下载期间新出现或修改的本地文件可能被覆盖 | 网络及图片处理结束后再次检查本地文件与编辑器，变化时保留内容 |
| 只检查首个打开的编辑器 | 检查所有打开的 Markdown 编辑器，任何未保存版本都受到保护 |
| 定时同步与 UI 说明不一致；删除可能无确认执行 | 自动同步不弹计划，删除留待手动确认；手动删除和强制重推必须预览 |
| “清空同步状态”漏掉文档和图片数据；设置页计数不准确 | 完整重置状态，按当前模式显示映射计数 |
| 无基线强制重推会创建重复文档 | 使用预览中已有 document_id 原位更新并恢复映射 |
| 文件镜像扁平模式拒绝自己生成的路径 | 正确解码标题；含分隔符的本地原始名字拒绝同步，避免歧义 |
| glob 中 `**/` 不能匹配零层目录 | 修正为匹配根目录与任意子目录；`?` 不跨目录 |
| 写请求在超时、断线或 5xx 后可能重发；上传失败可能再次中转新建 | 不重复结果不确定的写请求；中转仅针对明确参数拒绝；读请求仍可重试 |
| 普通读重试强制刷新 OAuth，且并发刷新没有合并 | 只在鉴权拒绝后强制刷新；同一轮用户令牌刷新共享请求；配置改变时不回写旧授权 |
| 授权请求无响应预算，本地回调监听所有网络接口 | 授权请求增加超时；回调只监听本机；取消会结束等待，使用随机安全 state |
| 列表缺字段、游标循环、深度截断会给出不完整扫描 | 直接终止同步；根页面识别失败及同名路径歧义也停止，避免推断错误删除或创建 |
| 附件缓存只检查文件是否存在 | 复核实际字节；图片上传失败保留映射但不记转换完成，下轮可重试 |
| 实验往返命令把当前笔记另发到飞书，遗留文档及可再次上传的报告 | 从正式插件移除实验命令、设置说明与两份实现；保留转换和同步测试 |
| 测试依赖个人 Work 路径，临时目录固定；历史失效分支和重复假服务方法残留 | 改为固定合成样例、独立临时目录、执行后清理；删除过时测试分支 |
| 无 README、安装脚本默认个人路径并跳过缺失文件 | 提供完整中文安装与配置说明；必须指定仓库、检查全部资产、备份旧安装并保留配置 |
| 开发产物与发布产物不区分、版本无一致性检查 | 生产构建压缩 CommonJS；检查版本一致；生成标准目录、只含三个文件的 ZIP 和 SHA-256 清单 |

## 验证

- 干净安装：使用锁文件执行 `npm ci --no-audit --no-fund` 成功。
- 类型检查：`tsc --noEmit` 通过。
- 转换回归：19 项，覆盖此前公式、代码围栏空行卡死及转换幂等问题。
- 运行安全回归：14 项，覆盖目录过滤、路径、目标切换、多编辑器、重试、令牌并发和分页完整性。
- 离线端到端：73 个场景，包含两种模式的同步、冲突、图片、删除、预览后修改/恢复和无基线强制重推。
- 生产包验证：真实 `main.js` 在模拟 Obsidian 宿主中加载并执行初始化；五条正式命令及默认设置正确。
- 安装验证：临时仓库中确认必需文件一致、旧版备份有效、`data.json` 与规则原样保留；未指定目标直接失败。
- 发布包：以独立 ZIP 解码器检查三个文件、CRC 与 SHA-256 清单，并检查重复构建的一致性。

执行环境为 macOS、Node.js 26.6.0、npm 11.18.0。源码构建声明 Node.js >= 20；本轮没有在 Windows、Linux、Node 20 或真实 Obsidian GUI 上另做验收。

本轮测试不连接真实飞书账号；2026-09-27 的线上公式验证属于历史记录。整篇更新、秒级远端时间戳、平台专有格式、重命名与目录页面正文等限制已在 README 中说明，不将离线测试通过等同于所有线上场景都无损。
