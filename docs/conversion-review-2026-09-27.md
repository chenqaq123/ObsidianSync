## 实现保护

- 共用数学扫描器，识别成对定界符、围栏长度、围栏类型、行内代码、CRLF、缩进代码及已生成的原生公式标签。
- 不把不完整的公式跨过代码块配对，不在已有块级公式内部再次提升行内公式。
- `source-format-diagnostics` 默认关闭；手动开启后只提示，不修改原稿。提示进入同步预览和结果报告，未变更的笔记也能看到提示。
- 规则刷新计划执行前再次核对本地正文、编辑器状态和远端正文；预览后更改规则必须重新生成计划。
- 调整规则说明或文件中的规则排列不引发刷新；诊断开关不引发刷新。执行顺序始终以插件内置顺序为准。
- 现有规则文件的开关会保留，新规则按默认值补入。原有代码块空行卡死修复继续受限时回归测试保护。

## 原稿末段建议写法

下面是供核对的替换示例，保留原意，将解释句与公式分开。未自动写回 Work 原稿。

```markdown
而是图片中的微小 adversarial perturbation 直接改变 VLM 的 token distribution：

$$
f_\theta(\text{user prompt},\text{screenshot})
$$

从原本输出：

$$
y_{\text{benign}} = \text{“点击帖子 / 阅读内容”}
$$

变成：

$$
y_{\text{attack}} = \text{攻击者指定的 API/action program}
$$

由于 WAA Agent 会把模型输出中的 API 调用直接执行：

$$
y_{\text{attack}} \rightarrow \text{API Executor} \rightarrow \text{OS side effect}
$$

所以这不是：恶意图片让模型“说了一些坏话”。
```
