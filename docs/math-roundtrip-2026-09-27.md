# Obsidian / 飞书双向公式规则复核

2026-09-27，基于 Work 中用户更新后的 `Research&Learning/2026.09 GUI Agent Prompt Injection.md`。本文补充并更新此前 PDF 检查报告中的公式处理结论。

## 两个平台的输出约定

| 情况 | Obsidian 本地 Markdown | 飞书云文档 |
| --- | --- | --- |
| 行内公式 | `$ x + y $` 归一化为 `$x + y$`，只去掉定界符紧贴的空白 | 使用原生行内公式，保持与前后文字的位置关系 |
| 公式内部空格 | 保留 `x + y`、`\text{Agent Memory}`、显式 TeX 空格；末尾 `\ ` 写为等价的 `\space{}` | 保留 TeX 内容，不把普通文字空格全部删除 |
| 块级公式 | `$$…$$` 允许空格和换行；下行不裁掉块内的空白 | 普通段落中的独立公式使用居中段落及原生公式；保留矩阵、对齐环境内的换行 |
| 独占一行的行内公式 | 纯排版差异时保留作者本地段落布局 | 可提升为独立居中公式；列表、引用、表格等结构内不随意拆段 |
| 转义字符 | 数学环境内裸 `#` 补成 `\#`；保留已有 `\_`、`\$` 和其他 TeX 命令 | 发送边界补偿接口吞掉的特定反斜杠，避免公式失效或含义改变 |
| 非公式内容 | 代码围栏、行内代码、缩进代码、YAML、链接地址、Wiki 链接、价格及转义美元符号不按公式处理 | 同样保护这些内容 |

这里的“行内不能有空格”指 `$` 紧贴内容的两侧，**不是删除整个公式内部的空格**。`$$$$` 本身是空定界符串，不是有效公式示例；块级写法是 `$$内容$$` 或两行 `$$` 包围多行内容。

## 飞书接口的实际差异

通过隔离临时文档验证了创建、覆盖更新、读取块数据、取回 Markdown 的完整路径，临时文档验证后均已清理。

1. `docs_ai` 写入时会吞掉部分 Markdown 标点前的一层反斜杠。仅在发送时补偿这些字符：`# $ _ * ~ [ ] & : < > + - =` 及反引号。不能把所有反斜杠翻倍，否则 `\frac`、`\text`、矩阵换行等会损坏。观测样例保存于 `tests/fixtures/feishu-math-escapes.json`。
2. 原生行内 `<latex>` 会把 XML 实体保留为字面内容，而 `<p align="center"><latex>…</latex></p>` 会解码实体。因此逻辑转换统一保存 XML 编码，发送时对行内、块级分开处理，避免 `<`、`&` 或字面 `&lt;` 发生错译。
3. 取回 Markdown 后执行下行公式规则。行内定界符空白会被清理，居中原生公式标签恢复为 `$$…$$`，不把飞书内部标签留在笔记中。
4. 创建和更新使用同一个发送适配器；发送转义不写回规则中间结果，防止重复处理造成反斜杠累积。

官方格式依据：[Obsidian 数学语法](https://obsidian.md/help/advanced-syntax)、[飞书 CLI XML 格式](https://github.com/larksuite/cli/blob/main/skills/lark-doc/references/lark-doc-xml.md)、[飞书 CLI Markdown 格式](https://github.com/larksuite/cli/blob/main/skills/lark-doc/references/lark-doc-md.md)。以上反斜杠及实体细节来自本次实测，不能仅凭 XML 规范推断。

## 同步行为修正

- 上行、下行均提供公式空白和 `#` 转义规则；新增下行原生标签还原。已有规则开关保留，新下行规则按默认值补齐。
- 纯排版差异走保留本地布局的路径时，仍执行 Obsidian 必需的公式修复，避免把无效的 `$ x $` 永久保留。
- 预览只生成计划，不提前推进远端时间戳。取消预览或规则变更后重新预览，仍能发现尚未拉取的远端正文。
- 上行或下行规则在预览后变更，旧计划失效，需重新预览。发布规则版本更新后，旧文档可在同步计划中刷新格式，并继续执行本地/远端改动保护。
- `source-format-diagnostics` 继续默认关闭；Work 中的现有关闭状态保留。

## 验证结果与边界

- 19 项规则测试通过，包含 Unicode 边缘空白、公式文字空格、矩阵、价格、代码、XML 实体、重复往返和此前代码块空行卡死问题。
- 62 个离线同步场景通过，覆盖首次下载、正常拉取、纯排版差异、下行开关、预览规则变更、冲突保护和复跑稳定性。
- 飞书在线验证：12 组测试公式在创建和更新后均逐字保留公式内容，行内/居中属性符合预期；取回后 12 处公式均满足 Obsidian 定界符约定，重复下行转换结果不变。
- Work 全部 48 篇笔记共识别 100 处公式，本地上行和下行规则重复应用均稳定。用户更新的目标文档识别 39 处公式，转换后仍为 39 处。检查不修改原稿。
- 额外复制目标文档公式到临时飞书文档的验证被自动审批拒绝，原因是涉及私有文档内容外发；未执行此复制，使用本地原稿检查和合成样例在线验证。
- 在线检查核对了飞书保存的公式内容、居中属性和取回结果，未逐页截图检查新版 PDF，也不宣称不同平台支持所有相同的 TeX 扩展。
